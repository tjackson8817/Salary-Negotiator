Salary Negotiator

Turns a real offer, real market data, and your real qualifications into an actual negotiation plan and counter-offer draft — not generic "just ask for more" advice.

Where this fits. Step 5 in the funnel — the sequel to Interview Prep Guide Builder's Recruiter Screen mode. That tool coaches you to state a range before an offer exists ("not a negotiation yet"). This tool picks up once an actual offer is on the table and it's time to negotiate for real.
The one rule that matters most in this whole tool: never invent or exaggerate a competing offer. A fabricated story in a draft message is bad output. A fabricated competing offer used in a real negotiation is a lie told to a real employer — one that can unravel and cost you the offer entirely. If you don't have a competing offer, leave that field blank. The guide will work with what's actually true.
1 · The Role & Company

Compensation varies heavily by location — this grounds both the market research and the company-specific research below.

2 · Your Background

Used to identify real differentiators to justify going above the initial number — attach the file instead when you paste the prompt into Claude if that's easier.

3 · The Offer

The more complete this is, the more precise the total-compensation translation below can be — but partial is fine too.

Helps the guide prioritize which levers to push if base salary itself turns out to be capped.

4 · Competing Offer optional

Leaving this blank is completely normal and the guide works fine without it. See the red banner above.

5 · Output

Results always come back as a downloadable Word document (.docx) — this is a reference guide you'll want on hand during the actual negotiation call or email exchange. Requires the Code execution and file creation setting in Claude (Settings → Capabilities).

Differentiators stay grounded. The guide only cites qualifications actually documented in your resume — it does not invent achievements, credentials, or experience to strengthen your negotiating position.
Market and company data comes from real search, never a guess. Every figure the guide cites gets sourced. If company-specific data turns out to be thin (often the case for smaller or private companies), the guide says so plainly rather than presenting generic market data as if it were specific to this employer.
